ΕΝΟΤΗΤΑ 5: Πίνακες (arrays)
Θεωρία (αναλυτική):
Τι είναι ένας πίνακας;
Ένας πίνακας (array) είναι μια σειρά από θέσεις μνήμης που κρατάνε πολλές τιμές του ίδιου τύπου, η μία δίπλα στην άλλη.
Αντί να φτιάξουμε 5 ξεχωριστές μεταβλητές a1, a2, a3, a4, a5, φτιάχνουμε έναν πίνακα a[5].

Δήλωση πίνακα:

c
int scores[5];     // πίνακας με 5 ακέραιους
float temps[10];   // πίνακας με 10 δεκαδικούς
char letters[3];   // πίνακας με 3 χαρακτήρες
Προσοχή: Ο αριθμός μέσα στις αγκύλες [ ] δείχνει πόσα στοιχεία χωράει ο πίνακας.

Πρόσβαση σε στοιχεία πίνακα:
Κάθε θέση έχει έναν δείκτη (index) που ξεκινάει από 0 (όχι από 1).

c
int numbers[4];
numbers[0] = 10;   // πρώτο στοιχείο
numbers[1] = 20;   // δεύτερο
numbers[2] = 30;   // τρίτο
numbers[3] = 40;   // τέταρτο
Αν προσπαθήσεις να πας στο numbers[4] → ΣΦΑΛΜΑ (γιατί 0,1,2,3 = 4 θέσεις)

Αρχικοποίηση πίνακα κατά τη δήλωση:

c
int scores[5] = {90, 85, 78, 92, 88};
Τότε:

scores[0] = 90

scores[1] = 85

scores[2] = 78

scores[3] = 92

scores[4] = 88

Μπορούμε και χωρίς το μέγεθος:

c
int scores[] = {90, 85, 78};   // αυτόματα γίνεται scores[3]
Εκτύπωση πίνακα με for:

c
int scores[5] = {90, 85, 78, 92, 88};

for (int i = 0; i < 5; i++) {
    printf("scores[%d] = %d\n", i, scores[i]);
}
Διάβασμα πίνακα από τον χρήστη:

c
int scores[5];

for (int i = 0; i < 5; i++) {
    printf("Δώσε βαθμό %d: ", i);
    scanf("%d", &scores[i]);
}
Προσοχή: Στη scanf βάζουμε &scores[i] (το & είναι απαραίτητο).

Συνηθισμένα λάθη:

int a[5]; a[5] = 10; → λάθος (το 5 είναι έξω από το 0-4)

Να ξεχνάς ότι η πρώτη θέση είναι 0, όχι 1

Να μη βάζεις & στη scanf για int (χρειάζεται)

Παράδειγμα – Άθροισμα πίνακα:

c
int numbers[4] = {5, 10, 15, 20};
int sum = 0;

for (int i = 0; i < 4; i++) {
    sum = sum + numbers[i];
}

printf("Άθροισμα: %d", sum);   // εκτυπώνει 50
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Ποια είναι η σωστή δήλωση πίνακα με 3 ακέραιους;
Α) int a(3);
Β) int[3] a;
Γ) int a[3];
Δ) array a[3];

2. Ποια είναι η πρώτη θέση (δείκτης) ενός πίνακα;
Α) 1
Β) 0
Γ) -1
Δ) a[1]

3. Τι θα εκτυπωθεί;

c
int a[3] = {5, 10, 15};
printf("%d", a[1]);
Α) 5
Β) 10
Γ) 15
Δ) Σφάλμα

4. Πόσα στοιχεία έχει ο πίνακας int data[10];;
Α) 9
Β) 10
Γ) 11
Δ) 1
