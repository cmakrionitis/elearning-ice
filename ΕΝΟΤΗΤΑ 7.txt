ΕΝΟΤΗΤΑ 7: Δείκτες (pointers)
Θεωρία (αναλυτική):
Τι είναι ένας δείκτης;
Δείκτης (pointer) είναι μια μεταβλητή που δεν κρατάει τιμή, αλλά κρατάει τη διεύθυνση μνήμης μιας άλλης μεταβλητής.
Σκεψου το σαν έναν "δρομολογητή" ή "δείκτη" που σου λέει που βρίσκεται κάτι.

Γιατί χρειαζόμαστε δείκτες;

Για να αλλάζουμε μεταβλητές μέσα από συναρτήσεις (π.χ. scanf χρειάζεται &)

Για να δουλεύουμε με πίνακες πιο αποδοτικά

Για δυναμική διαχείριση μνήμης (αποθήκευση χωρίς να ξέρουμε πόσα δεδομένα θα έχουμε)

Βασικοί τελεστές δεικτών:

Τελεστής	Όνομα	        Τι κάνει
&	        address of	    δίνει τη διεύθυνση μιας μεταβλητής
*	        dereference	    πάει στη διεύθυνση που δείχνει ο δείκτης και διαβάζει/αλλάζει την τιμή
Παράδειγμα 1 – Πώς δηλώνουμε και χρησιμοποιούμε δείκτη:

c
int x = 10;        // κανονική μεταβλητή
int *ptr;          // δείκτης σε int (το * σημαίνει "δείκτης σε")
ptr = &x;          // ptr δείχνει στη διεύθυνση του x

printf("%d\n", x);     // 10
printf("%p\n", ptr);   // διεύθυνση μνήμης (π.χ. 0x7ffd...)
printf("%d\n", *ptr);  // 10 → το *ptr διαβάζει την τιμή στη διεύθυνση που δείχνει
Παράδειγμα 2 – Αλλαγή τιμής μέσω δείκτη:

c
int a = 5;
int *p = &a;

*p = 20;        // αλλάζει την τιμή του a (μέσω του δείκτη)

printf("%d", a);   // εκτυπώνει 20, ΟΧΙ 5!
Δεν άλλαξες τον δείκτη. Άλλαξες αυτό που δείχνει!

Παράδειγμα 3 – Γιατί χρειαζόμαστε δείκτες στη scanf (που ήδη ξέρεις):

c
int age;
scanf("%d", &age);   // το &age είναι δείκτης στο age
Η scanf παίρνει μια διεύθυνση για να βάλει την τιμή ΑΠΕΥΘΕΙΑΣ στη μεταβλητή.

Παράδειγμα 4 – Συνάρτηση που αλλάζει μεταβλητή (πολύ χρήσιμο):

c
#include <stdio.h>

void doubleValue(int *n) {
    *n = *n * 2;     // αλλάζει την τιμή στην οποία δείχνει ο δείκτης
}

int main() {
    int x = 7;
    doubleValue(&x);   // περνάμε τη διεύθυνση του x
    printf("%d", x);   // εκτυπώνει 14 (ΟΧΙ 7!)
    return 0;
}
Αν δεν χρησιμοποιούσες δείκτη, η doubleValue δεν θα μπορούσε να αλλάξει το x.

Δείκτες και πίνακες (πολύ στενή σχέση):

c
int arr[3] = {10, 20, 30};
int *p = arr;       // χωρίς & – το arr είναι ήδη δείκτης

printf("%d\n", *p);       // 10 (πρώτο στοιχείο)
printf("%d\n", *(p + 1)); // 20 (δεύτερο στοιχείο)
printf("%d\n", p[2]);     // 30 (και αυτό δουλεύει!)
Ισότητα: arr[i] = *(arr + i)

Τι σημαίνει NULL;
Ένας δείκτης που δεν δείχνει πουθενά:

c
int *ptr = NULL;
Αποφεύγουμε να χρησιμοποιήσουμε *ptr αν είναι NULL (πέφτει το πρόγραμμα).

Συνήθη λάθη με δείκτες:

int *p; *p = 5; → λάθος (δεν ξέρουμε πού δείχνει ο p)

Να ξεχνάμε το & στη scanf

int *p = 5; → λάθος (θέλει διεύθυνση, όχι τιμή)

Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Τι σημαίνει το & μπροστά από μια μεταβλητή;

c
int x = 10;
int *p = &x;
Α) Την τιμή του x
Β) Τη διεύθυνση του x
Γ) Τον πολλαπλασιασμό
Δ) Τη δήλωση δείκτη

2. Τι θα εκτυπωθεί;

c
int a = 8;
int *p = &a;
*p = 12;
printf("%d", a);
Α) 8
Β) 12
Γ) Διεύθυνση
Δ) Σφάλμα

3. Πώς δηλώνεται ένας δείκτης σε int;
Α) int p;
Β) &int p;
Γ) int* p;
Δ) pointer p;

4. Στον κώδικα scanf("%d", &x);, το &x είναι:
Α) Αριθμός
Β) Δείκτης στο x
Γ) Η τιμή του x
Δ) Σφάλμα
