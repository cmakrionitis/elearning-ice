ΕΝΟΤΗΤΑ 1: Η βασική δομή ενός προγράμματος C (Hello World!)
Θεωρία (αναλυτική):
Τι είναι ένα πρόγραμμα στη C;
Κάθε πρόγραμμα C είναι ένα σύνολο εντολών που εκτελούνται σειριακά (η μία μετά την άλλη). Το πρόγραμμα ξεκινάει από μία συγκεκριμένη συνάρτηση που λέγεται main.

Η πιο απλή δομή ενός προγράμματος C:

c
#include <stdio.h>

int main() {
    // οι εντολές γράφονται εδώ
    return 0;
}
Ας δούμε κάθε γραμμή ξεχωριστά:

Γραμμή	Τι σημαίνει

#include <stdio.h>	Βάζει στο πρόγραμμα βιβλιοθήκη για είσοδο/έξοδο (για να δουλέψουν οι printf και scanf)
int main()	Η αρχή του προγράμματος. Το πρόγραμμα ξεκινάει από εδώ.
{ }	Οι αγκύλες ορίζουν που αρχίζει και τελειώνει το σώμα της main
return 0;	Λέει ότι το πρόγραμμα τελείωσε επιτυχημένα
//	Σχόλιο — το αγνοεί ο υπολογιστής, είναι για εμάς
Το πρώτο μας πρόγραμμα: Hello World!

c
#include <stdio.h>

int main() {
    printf("Hello World!");
    return 0;
}
Τι κάνει;
Η printf εκτυπώνει στην οθόνη το μήνυμα Hello World!.

Σημεία που πρέπει να θυμάσαι:

Κάθε εντολή τελειώνει με ερωτηματικό ;
Αν το ξεχάσεις, το πρόγραμμα δεν θα δουλέψει.

Η main είναι υποχρεωτική
Δεν μπορείς να έχεις πρόγραμμα C χωρίς main. Είναι η είσοδος.

Τα σχόλια βοηθάνε
Μπορείς να γράψεις σχόλια με // (για μία γραμμή) ή /* ... */ (για πολλές γραμμές).

Πεζά/κεφαλαία έχουν σημασία
Το Printf είναι διαφορετικό από το printf. Η C είναι case-sensitive.

Τα κενά δεν πειράζουν
Μπορείς να βάζεις αλλαγές γραμμής και κενά για να φαίνεται όμορφα.

Παράδειγμα με σχόλια:

c
#include <stdio.h>   // Για printf

int main() {         // Ξεκινάει το πρόγραμμα
    printf("Γεια σου κόσμε!");   // Εκτύπωση μηνύματος
    return 0;        // Επιτυχής τερματισμός
}
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Ποια συνάρτηση είναι υποχρεωτική σε κάθε πρόγραμμα C;
Α) printf
Β) start
Γ) main
Δ) hello

2. Τι κάνει η #include <stdio.h>;
Α) Εκτυπώνει κείμενο
Β) Διαβάζει δεδομένα
Γ) Βάζει βιβλιοθήκη για είσοδο/έξοδο
Δ) Τερματίζει το πρόγραμμα

3. Τι λείπει από τον παρακάτω κώδικα;

c
#include <stdio.h>

int main() {
    printf("Hello")
    return 0;
}
Α) ; μετά το "Hello"
Β) } στο τέλος
Γ) #include λάθος
Δ) Τίποτα

4. Τι θα εκτυπωθεί;

c
#include <stdio.h>

int main() {
    printf("Γεια");
    printf(" σου");
    return 0;
}

Α) Γεια σου
Β) Γειάσου
Γ) Γεια  
   σου
Δ) Γεια σου (σε δύο γραμμές)
