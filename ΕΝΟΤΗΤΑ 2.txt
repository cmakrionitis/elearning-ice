ΕΝΟΤΗΤΑ 2: Μεταβλητές, τύποι δεδομένων & είσοδος/έξοδος
Θεωρία (αναλυτική):
Τι είναι μεταβλητή;
Μια μεταβλητή είναι σαν ένα «κουτάκι» στη μνήμη του υπολογιστή που κρατάει μια τιμή. Κάθε μεταβλητή έχει όνομα, τύπο και τιμή.

Βασικοί τύποι δεδομένων στη C:

Τύπος	        Περιγραφή	                        Παράδειγμα
int	            Ακέραιοι αριθμοί	                5, -3, 100
float	        Δεκαδικοί (κινητής υποδιαστολής)	3.14, 2.5
char	        Ένας χαρακτήρας	                    'A', 'm', '9'
Δήλωση μεταβλητών:
Πρώτα γράφουμε τον τύπο, μετά το όνομα.

c
int age;
float height;
char initial;
Ταυτόχρονη δήλωση + αρχικοποίηση:

c
int age = 20;
float height = 1.75;
char initial = 'M';
Έξοδος (εκτύπωση) με printf:
Η printf() χρησιμοποιεί placeholders (προσδιοριστές μορφοποίησης) ανάλογα με τον τύπο:

%d για int

%f για float

%c για char

c
int x = 10;
printf("Η τιμή του x είναι %d", x);   // εκτυπώνει: Η τιμή του x είναι 10
Είσοδος (διάβασμα) με scanf:
Η scanf() διαβάζει τιμή από το πληκτρολόγιο. Χρειάζεται το σύμβολο & μπροστά από τη μεταβλητή (γιατί αποθηκεύει την τιμή απευθείας στη μνήμη).

c
int age;
printf("Δώσε ηλικία: ");
scanf("%d", &age);   // ο χρήστης γράφει έναν αριθμό
Παραδείγματα εκτύπωσης float:

c
float pi = 3.14159;
printf("%.2f", pi);   // εκτυπώνει 3.14 (2 δεκαδικά)
printf("%f", pi);     // εκτυπώνει 3.141590
Σημαντικό: Για να χρησιμοποιήσουμε printf και scanf πρέπει να έχουμε τη γραμμή:

c
#include <stdio.h>
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Ποιος τύπος δεδομένων είναι σωστός για έναν ακέραιο αριθμό;
Α) float
Β) int
Γ) char
Δ) double

2. Τι θα εκτυπώσει ο παρακάτω κώδικας;

c
int x = 7;
printf("%d", x / 2);
Α) 3.5
Β) 3
Γ) 4
Δ) 7/2

3. Τι λείπει από την εντολή scanf("%d", x); για να δουλέψει σωστά;
Α) Τίποτα
Β) & μπροστά από το x
Γ) * μπροστά από το x
Δ) # μπροστά από το x

4. Ποια βιβλιοθήκη είναι απαραίτητη για printf και scanf;
Α) <math.h>
Β) <string.h>
Γ) <stdio.h>
Δ) <stdlib.h>
