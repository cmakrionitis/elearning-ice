ΕΝΟΤΗΤΑ 9: Δυναμική Διαχείριση Μνήμης (malloc, free)
Θεωρία (αναλυτική):
Τι είναι η δυναμική μνήμη;
Μέχρι τώρα, όταν δηλώναμε πίνακες, έπρεπε να ξέρουμε το μέγεθός τους εκ των προτέρων:

c
int scores[100];   // 100 θέσεις, ακόμα κι αν χρειαζόμαστε μόνο 3
Με τη δυναμική μνήμη, μπορούμε να ζητήσουμε μνήμη κατά την εκτέλεση του προγράμματος, ανάλογα με τις ανάγκες μας.

Γιατί χρειαζόμαστε δυναμική μνήμη;

Δεν ξέρουμε πόσα δεδομένα θα δώσει ο χρήστης

Θέλουμε να εξοικονομήσουμε μνήμη (να μην δεσμεύουμε περισσότερη από όση χρειαζόμαστε)

Θέλουμε να δημιουργούμε δομές που μεγαλώνουν όσο χρειάζεται (π.χ. λίστες)

Οι συναρτήσεις που χρειαζόμαστε (από <stdlib.h>):

Συνάρτηση	                Τι κάνει
malloc(bytes)	            Δεσμεύει μνήμη και επιστρέφει δείκτη στην αρχή της
calloc(count, size)	        Δεσμεύει μνήμη για πίνακα και μηδενίζει όλα τα στοιχεία
free(ptr)	                Απελευθερώνει τη μνήμη που είχαμε δεσμεύσει
realloc(ptr, newSize)	    Αλλάζει το μέγεθος μιας ήδη δεσμευμένης μνήμης

Παράδειγμα 1 – Δέσμευση μνήμης για έναν ακέραιο:

c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int*)malloc(sizeof(int));   // δέσμευση μνήμης για 1 int
    
    if (p == NULL) {
        printf("Αποτυχία δέσμευσης μνήμης!\n");
        return 1;
    }
    
    *p = 42;
    printf("Τιμή: %d\n", *p);
    
    free(p);   // ΑΠΕΛΕΥΘΕΡΩΣΗ (πολύ σημαντικό!)
    return 0;
}
Τι κάνει η malloc(sizeof(int));
Ζητάει από τον υπολογιστή sizeof(int) bytes (συνήθως 4) και επιστρέφει τη διεύθυνση που αρχίζει αυτή η μνήμη.

Το (int*) → λέει στον compiler ότι ο δείκτης είναι για int.

Παράδειγμα 2 – Δυναμικός πίνακας (το πιο χρήσιμο):

c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    printf("Πόσους αριθμούς θες να δώσεις; ");
    scanf("%d", &n);
    
    // Δέσμευση μνήμης για πίνακα με n ακέραιους
    int *arr = (int*)malloc(n * sizeof(int));
    
    if (arr == NULL) {
        printf("Δεν μπόρεσα να δεσμεύσω μνήμη!\n");
        return 1;
    }
    
    // Διάβασμα τιμών
    for (int i = 0; i < n; i++) {
        printf("Δώσε αριθμό %d: ", i + 1);
        scanf("%d", &arr[i]);
    }
    
    // Εκτύπωση
    printf("Οι αριθμοί που έδωσες: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    
    free(arr);   // ΠΑΝΤΑ ελευθερώνουμε τη μνήμη!
    return 0;
}
Παράδειγμα 3 – realloc (μεγαλώνουμε τον πίνακα):

c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr = (int*)malloc(3 * sizeof(int));
    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;
    
    // Θέλουμε να προσθέσουμε κι άλλο στοιχείο
    arr = (int*)realloc(arr, 4 * sizeof(int));
    arr[3] = 40;
    
    for (int i = 0; i < 4; i++) {
        printf("%d ", arr[i]);
    }
    
    free(arr);
    return 0;
}
Παράδειγμα 4 – Δυναμικός πίνακας από struct:

c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char name[50];
    int age;
} Student;

int main() {
    int n;
    printf("Πόσους φοιτητές; ");
    scanf("%d", &n);
    
    Student *students = (Student*)malloc(n * sizeof(Student));
    
    for (int i = 0; i < n; i++) {
        printf("Όνομα φοιτητή %d: ", i + 1);
        scanf("%s", students[i].name);
        printf("Ηλικία: ");
        scanf("%d", &students[i].age);
    }
    
    printf("\nΦοιτητές:\n");
    for (int i = 0; i < n; i++) {
        printf("%s, %d ετών\n", students[i].name, students[i].age);
    }
    
    free(students);
    return 0;
}
Σημαντικές παρατηρήσεις:

ΠΑΝΤΑ ελέγχουμε αν η malloc επέστρεψε NULL
(αν δεν υπάρχει αρκετή μνήμη, επιστρέφει NULL)

ΠΑΝΤΑ καλούμε free()
Αν δεν ελευθερώσουμε μνήμη, έχουμε memory leak (η μνήμη μένει δεσμευμένη και χάνεται)

Μετά το free, ο δείκτης πετάει (dangling pointer)
Καλό είναι μετά το free να βάζουμε ptr = NULL;

Προσοχή: Οι δυναμικοί πίνακες προσπελάζονται κανονικά με [ ]

Σύγκριση στατικού vs δυναμικού πίνακα:

Στατικός πίνακας	            Δυναμικός πίνακας
int arr[100];	                int *arr = malloc(n * sizeof(int));
Μέγεθος γνωστό από πριν	        Μέγεθος ό,τι θέλουμε
Δεν χρειάζεται free	            Χρειάζεται free
Δεσμεύεται μνήμη στην αρχή	    Δεσμεύεται όταν το χρειαζόμαστε

Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)

1. Ποια συνάρτηση δεσμεύει δυναμική μνήμη;
Α) alloc()
Β) malloc()
Γ) create()
Δ) new()

2. Ποια βιβλιοθήκη χρειάζεται για malloc και free;
Α) <stdio.h>
Β) <string.h>
Γ) <stdlib.h>
Δ) <math.h>

3. Τι κάνει η free(ptr);;
Α) Δεσμεύει μνήμη
Β) Απελευθερώνει τη μνήμη που δείχνει ο ptr
Γ) Διαγράφει τον δείκτη ptr
Δ) Μηδενίζει την τιμή του ptr

4. Τι ελέγχουμε μετά από malloc για να δούμε αν πέτυχε;

c
int *p = malloc(100 * sizeof(int));
Α) if (p > 0)
Β) if (p != NULL)
Γ) if (p == 0)
Δ) if (*p == NULL)
