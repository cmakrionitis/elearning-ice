ΕΝΟΤΗΤΑ 3: Συνθήκες (if, if-else, else if)
Θεωρία (αναλυτική):
Γιατί χρειαζόμαστε συνθήκες;
Τα προγράμματα συχνά πρέπει να παίρνουν αποφάσεις. Οι συνθήκες επιτρέπουν στο πρόγραμμα να εκτελέσει διαφορετικό κώδικα ανάλογα με κάποια κατάσταση.

Η βασική δομή if:

c
if (συνθήκη) {
    // εκτελείται ΜΟΝΟ αν η συνθήκη είναι αληθής
}
if-else:
Όταν θέλουμε δύο επιλογές (αληθές ή ψευδές).

c
if (συνθήκη) {
    // εκτελείται αν αληθής
} else {
    // εκτελείται αν ψευδής
}
else if:
Για περισσότερες από δύο περιπτώσεις.

c
if (συνθήκη1) {
    // εκτελείται αν η συνθήκη1 είναι αληθής
} else if (συνθήκη2) {
    // εκτελείται αν η συνθήκη1 είναι ψευδής ΚΑΙ η συνθήκη2 αληθής
} else {
    // εκτελείται αν καμία δεν είναι αληθής
}
Τελεστές σύγκρισης (βασικοί):

Τελεστής	    Σημασία	            Παράδειγμα
==	            ίσο	                if (x == 5)
!=	            διάφορο	            if (x != 5)
>	            μεγαλύτερο	        if (x > 5)
<	            μικρότερο	        if (x < 5)
>=	            μεγαλύτερο ή ίσο	if (x >= 5)
<=	            μικρότερο ή ίσο	    if (x <= 5)
ΠΡΟΣΟΧΗ: Μην μπερδεύετε = (ανάθεση τιμής) με == (σύγκριση)!

Λογικοί τελεστές (για πολλές συνθήκες ταυτόχρονα):

&& → AND (όλες πρέπει να είναι αληθείς)

|| → OR (τουλάχιστον μία πρέπει να είναι αληθής)

Παράδειγμα:

c
if (age >= 18 && hasID == 1) {
    printf("Μπορείς να ψηφίσεις");
}
Παραδείγματα:

c
int score = 85;

if (score >= 90) {
    printf("Άριστα");
} else if (score >= 80) {
    printf("Πολύ καλά");
} else if (score >= 70) {
    printf("Καλά");
} else {
    printf("Χρειάζεται βελτίωση");
}
Σημαντικό:

Οι αγκύλες { } δεν είναι πάντα υποχρεωτικές αν έχουμε ΜΙΑ μόνο εντολή, αλλά καλό είναι να τις βάζουμε για ευκρίνεια.

Οι συνθήκες γράφονται πάντα σε παρενθέσεις ( ).

Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Τι θα εκτυπωθεί;

c
int x = 7;
if (x > 10) {
    printf("Μεγάλο");
} else {
    printf("Μικρό");
}
Α) Μεγάλο
Β) Μικρό
Γ) Τίποτα
Δ) Σφάλμα

2. Ποιος τελεστής χρησιμοποιείται για να ελέγξουμε αν δύο τιμές είναι ίσες;
Α) =
Β) ==
Γ) !=
Δ) <>

3. Ποια συνθήκη είναι αληθής όταν το a είναι 15 και το b είναι 10;
Α) a < b
Β) a == b
Γ) a > b
Δ) a <= b

4. Τι θα εκτυπωθεί;

c
int temp = 25;
if (temp > 30) {
    printf("Ζέστη");
} else if (temp > 20) {
    printf("Ωραία");
} else {
    printf("Κρύο");
}
Α) Ζέστη
Β) Ωραία
Γ) Κρύο
Δ) ΖέστηΩραία
