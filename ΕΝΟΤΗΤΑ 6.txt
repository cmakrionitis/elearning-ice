ΕΝΟΤΗΤΑ 6: Συναρτήσεις (functions)
Θεωρία (αναλυτική):
Τι είναι μια συνάρτηση;
Συνάρτηση είναι ένα κομμάτι κώδικα που γράφεται μία φορά και μπορεί να χρησιμοποιηθεί πολλές φορές. Χωρίζουμε το πρόγραμμα σε μικρότερα, οργανωμένα κομμάτια για να είναι πιο κατανοητό και εύκολο στη συντήρηση.

Γιατί χρησιμοποιούμε συναρτήσεις;

Αποφεύγουμε να γράφουμε τον ίδιο κώδικα ξανά και ξανά

Το πρόγραμμα γίνεται πιο καθαρό και διαβαστερό

Είναι πιο εύκολο να βρούμε λάθη

Μπορούμε να χρησιμοποιήσουμε την ίδια συνάρτηση σε διαφορετικά σημεία

Δομή μιας συνάρτησης:

c
return_type function_name(parameters) {
    // κώδικας της συνάρτησης
    return value;   // αν δεν επιστρέφει τίποτα, δεν χρειάζεται
}
Τα μέρη μιας συνάρτησης:

Μέρος	Τι σημαίνει	Παράδειγμα
return_type	Τι είδους τιμή επιστρέφει	int, float, void (τίποτα)
function_name	Το όνομα της συνάρτησης	add, printHello
parameters	Δεδομένα που δέχεται	int a, int b
return	Τι επιστρέφει (αν επιστρέφει)	return sum;
Παράδειγμα 1 – Συνάρτηση που ΠΡΟΣΘΕΤΕΙ δύο αριθμούς:

c
#include <stdio.h>

// Δήλωση συνάρτησης (prototype)
int add(int x, int y);

int main() {
    int result = add(5, 3);
    printf("Το άθροισμα είναι: %d", result);  // εκτυπώνει 8
    return 0;
}

// Ορισμός συνάρτησης
int add(int x, int y) {
    int sum = x + y;
    return sum;
}
Παράδειγμα 2 – Συνάρτηση που ΔΕΝ επιστρέφει τίποτα (void):

c
#include <stdio.h>

void printMessage(void);

int main() {
    printMessage();     // καλεί τη συνάρτηση
    printMessage();     // μπορούμε να την καλέσουμε πολλές φορές
    return 0;
}

void printMessage(void) {
    printf("Καλώς ήρθες στο μάθημα C!\n");
}
Η void σημαίνει "τίποτα" → η συνάρτηση δεν επιστρέφει τιμή.

Παράδειγμα 3 – Συνάρτηση με παραμέτρους:

c
#include <stdio.h>

void greet(char name[]) {
    printf("Γεια σου, %s!\n", name);
}

int main() {
    greet("Μαρία");
    greet("Γιάννης");
    return 0;
}
/* Εκτυπώνει:
   Γεια σου, Μαρία!
   Γεια σου, Γιάννης!
*/
Τι είναι το return;

Σταματάει την εκτέλεση της συνάρτησης

Επιστρέφει μία τιμή εκεί που κλήθηκε η συνάρτηση

c
int square(int x) {
    return x * x;   // επιστρέφει το τετράγωνο και σταματάει
}

// Στη main:
int result = square(4);  // result = 16
Σημαντικές παρατηρήσεις:

Η main είναι και αυτή συνάρτηση – ειδική, γιατί εκεί ξεκινάει το πρόγραμμα.

Prototype (δήλωση πριν τη main):
Ενημερώνει τον compiler ότι υπάρχει μια συνάρτηση. Δεν είναι πάντα υποχρεωτικό αν η συνάρτηση γράφεται πριν τη main.

Οι παράμετροι είναι σαν "τοπικές μεταβλητές" – υπάρχουν μόνο μέσα στη συνάρτηση.

Σύγκριση κώδικα με και χωρίς συνάρτηση:

Χωρίς συνάρτηση (κακός – επαναλαμβανόμενος κώδικας):

c
printf("Γεια σου Μαρία!\n");
printf("Γεια σου Γιάννη!\n");
printf("Γεια σου Κώστα!\n");
Με συνάρτηση (καλός – DRY = Don't Repeat Yourself):

c
void sayHello(char name[]) {
    printf("Γεια σου %s!\n", name);
}
sayHello("Μαρία");
sayHello("Γιάννη");
sayHello("Κώστα");
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Ποια λέξη χρησιμοποιείται όταν μια συνάρτηση δεν επιστρέφει τίποτα;
Α) int
Β) float
Γ) void
Δ) empty

2. Τι θα εκτυπωθεί;

c
int triple(int x) {
    return x * 3;
}

int main() {
    int result = triple(5);
    printf("%d", result);
    return 0;
}
Α) 5
Β) 15
Γ) 8
Δ) 3

3. Ποια είναι η σωστή κλήση της συνάρτησης;

c
void show(int a, int b) {
    printf("%d %d", a, b);
}
Α) show(5);
Β) show(5, 10);
Γ) show();
Δ) show(5, 10, 15);

4. Τι κάνει η εντολή return; (χωρίς τιμή) σε μια void συνάρτηση;
Α) Επιστρέφει 0
Β) Βγάζει σφάλμα
Γ) Σταματάει τη συνάρτηση
Δ) Εκτυπώνει κενό
