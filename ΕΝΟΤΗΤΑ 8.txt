ΕΝΟΤΗΤΑ 8: Δομές (struct)
Θεωρία (αναλυτική):
Τι είναι μια δομή (struct);
Μια δομή είναι ένας τρόπος να ομαδοποιήσουμε διαφορετικούς τύπους δεδομένων σε ένα νέο σύνθετο τύπο.

Με τους πίνακες μπορούσαμε να αποθηκεύσουμε πολλά στοιχεία, αλλά ίδιου τύπου.
Με τις δομές μπορούμε να αποθηκεύσουμε διαφορετικά στοιχεία για το ίδιο "αντικείμενο" (π.χ. όνομα, ηλικία, βαθμό).

Γιατί χρειαζόμαστε struct;
Ας πούμε ότι θέλουμε να αποθηκεύσουμε δεδομένα για έναν φοιτητή:

Όνομα (string)

Ηλικία (int)

Βαθμό (float)

Χωρίς struct, θα χρειαζόμασταν 3 ξεχωριστές μεταβλητές.
Με struct, τα ομαδοποιούμε σε ένα "πακέτο".

Δήλωση μιας δομής:

c
struct Student {
    char name[50];
    int age;
    float grade;
};
Προσοχή: Δεν δημιουργήσαμε ακόμα μεταβλητή. Απλά ορίσαμε πώς μοιάζει ένας φοιτητής.

Δημιουργία μεταβλητής τύπου struct:

c
struct Student s1;
Πρόσβαση στα μέλη μιας δομής (χρησιμοποιούμε τελεία .):

c
s1.age = 20;
s1.grade = 8.5;
strcpy(s1.name, "Μαρία");   // για string χρειάζεται strcpy
Αρχικοποίηση κατά τη δήλωση:

c
struct Student s1 = {"Γιάννης", 22, 9.2};
Εκτύπωση μελών δομής:

c
printf("Όνομα: %s\n", s1.name);
printf("Ηλικία: %d\n", s1.age);
printf("Βαθμός: %.1f\n", s1.grade);
Πίνακας από struct:

c
struct Student class[3] = {
    {"Μαρία", 20, 8.5},
    {"Γιάννης", 22, 9.2},
    {"Κώστας", 21, 7.8}
};

// Εκτύπωση όλων
for (int i = 0; i < 3; i++) {
    printf("%s: %.1f\n", class[i].name, class[i].grade);
}
Struct ως παράμετρος σε συνάρτηση:

c
void printStudent(struct Student s) {
    printf("%s, %d ετών, βαθμός %.1f\n", s.name, s.age, s.grade);
}

// Κλήση:
printStudent(s1);
Δείκτης σε struct (πολύ χρήσιμο):

c
struct Student *ptr = &s1;

// Δύο τρόποι πρόσβασης:
(*ptr).age = 25;     // παλιός τρόπος
ptr->age = 25;       // νέος τρόπος (προτιμάται)
Ο τελεστής -> χρησιμοποιείται όταν έχουμε δείκτη σε struct.

Παράδειγμα 1 – Απλή δομή:

c
#include <stdio.h>
#include <string.h>

struct Book {
    char title[100];
    int pages;
    float price;
};

int main() {
    struct Book b1 = {"C Programming", 350, 29.99};
    
    printf("Βιβλίο: %s\n", b1.title);
    printf("Σελίδες: %d\n", b1.pages);
    printf("Τιμή: %.2f\n", b1.price);
    
    return 0;
}
Παράδειγμα 2 – Συνάρτηση που αλλάζει struct με δείκτη:

c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[50];
    int age;
};

void birthday(struct Student *s) {
    s->age = s->age + 1;    // αυξάνει την ηλικία
}

int main() {
    struct Student s1 = {"Μαρία", 20};
    
    birthday(&s1);     // περνάμε διεύθυνση
    
    printf("%s έγινε %d ετών\n", s1.name, s1.age);
    return 0;
}
Σημαντικές παρατηρήσεις:

Τα struct μπορούν να περιέχουν πίνακες, άλλα struct, ακόμα και δείκτες

Για strings μέσα σε struct, χρησιμοποιούμε strcpy για αντιγραφή

Το typedef μπορεί να κάνει τη δήλωση πιο σύντομη:

c
typedef struct {
    char name[50];
    int age;
} Student;

Student s1;   // δεν χρειάζεται "struct" μπροστά
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Πώς προσβάλλουμε το μέλος age μιας μεταβλητής s1 που είναι struct;

c
struct Person {
    char name[50];
    int age;
};
struct Person s1;
Α) s1->age
Β) s1.age
Γ) age(s1)
Δ) s1[age]

2. Τι κάνει ο τελεστής ->;
Α) Προσβάλλει μέλος struct από δείκτη
Β) Προσβάλλει μέλος struct από μεταβλητή
Γ) Δηλώνει struct
Δ) Δημιουργεί δείκτη

3. Τι θα εκτυπωθεί;

c
struct Point {
    int x;
    int y;
};

int main() {
    struct Point p1 = {3, 7};
    printf("%d", p1.x + p1.y);
    return 0;
}
Α) 3
Β) 7
Γ) 10
Δ) 37

4. Ποια βιβλιοθήκη χρειάζεται για να χρησιμοποιήσουμε strcpy με strings μέσα σε struct;
Α) <stdio.h>
Β) <stdlib.h>
Γ) <string.h>
Δ) <math.h>
