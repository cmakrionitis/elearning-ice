ΕΝΟΤΗΤΑ 4: Επαναλήψεις (for, while, do-while)
Θεωρία (αναλυτική):
Τι είναι οι επαναλήψεις (βρόχοι);
Όταν θέλουμε να εκτελέσουμε την ίδια εντολή ή μπλοκ εντολών πολλές φορές, χρησιμοποιούμε επαναλήψεις. Χωρίς αυτές, θα έπρεπε να γράψουμε τον ίδιο κώδικα ξανά και ξανά.

1. Βρόχος for – Όταν γνωρίζουμε ακριβώς πόσες φορές θα επαναληφθεί.

Δομή:

c
for (αρχικοποίηση; συνθήκη; βήμα) {
    // κώδικας που επαναλαμβάνεται
}
Παράδειγμα – εκτύπωση αριθμών 0,1,2,3,4:

c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
Πώς δουλεύει:

int i = 0 → εκτελείται μία φορά στην αρχή

i < 5 → ελέγχεται πριν από κάθε επανάληψη (αν ψευδής, σταματάει)

printf("%d ", i) → εκτελείται αν η συνθήκη είναι αληθής

i++ → εκτελείται μετά από κάθε επανάληψη

2. Βρόχος while – Όταν δεν ξέρουμε πόσες επαναλήψεις θα γίνουν. Ελέγχει πρώτα την συνθήκη, μετά εκτελεί.

Δομή:

c
while (συνθήκη) {
    // κώδικας που επαναλαμβάνεται όσο η συνθήκη είναι αληθής
}
Παράδειγμα – διάβασμα αριθμών μέχρι ο χρήστης να δώσει το 0:

c
int num = 1;
while (num != 0) {
    printf("Δώσε αριθμό (0 για έξοδο): ");
    scanf("%d", &num);
}
3. Βρόχος do-while – Παρόμοιος με while, αλλά ελέγχει μετά την εκτέλεση. Εκτελείται τουλάχιστον μία φορά πάντα.

Δομή:

c
do {
    // κώδικας που εκτελείται τουλάχιστον μία φορά
} while (συνθήκη);
Παράδειγμα – μενού επιλογών:

c
int choice;
do {
    printf("1. Έναρξη\n2. Έξοδος\nΕπιλογή: ");
    scanf("%d", &choice);
} while (choice != 2);
Έξοδος από βρόχο – break:

c
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;    // σταματάει τον βρόχο όταν i == 5
    }
    printf("%d ", i);   // εκτυπώνει 0 1 2 3 4
}
Παράλειψη επανάληψης – continue:

c
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue;   // παραλείπει το printf όταν i == 2
    }
    printf("%d ", i);   // εκτυπώνει 0 1 3 4
}
Ερωτήσεις πολλαπλής επιλογής (4 ερωτήσεις)
1. Πόσες φορές θα εκτυπωθεί η λέξη "Γεια";

c
for (int i = 0; i < 3; i++) {
    printf("Γεια");
}
Α) 2
Β) 3
Γ) 4
Δ) 1

2. Ποιος βρόχος εκτελείται τουλάχιστον μία φορά ακόμα κι αν η συνθήκη είναι ψευδής;
Α) for
Β) while
Γ) do-while
Δ) κανένας

3. Τι θα εκτυπωθεί;

c
int i = 0;
while (i < 2) {
    printf("%d", i);
    i++;
}
Α) 0
Β) 01
Γ) 012
Δ) 1

4. Τι κάνει η εντολή break; μέσα σε έναν βρόχο;
Α) Συνεχίζει στην επόμενη επανάληψη
Β) Βγαίνει από τον βρόχο
Γ) Τερματίζει όλο το πρόγραμμα
Δ) Κάνει επανεκκίνηση του βρόχου
